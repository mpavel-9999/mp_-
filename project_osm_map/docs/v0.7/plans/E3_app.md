# План этапа Э3 — каркас Android-приложения

Основа: [03_implementation_spec.md](../03_implementation_spec.md) раздел 3 (Э3), 5.1–5.5, 7; [04_product_architecture.md](../04_product_architecture.md) 6.5 и 8; контракт API — [server/openapi.yaml](../../../server/openapi.yaml), итог Э2 — [E2_api.md](E2_api.md).
Результат: `app/` переведён на Jetpack Compose. Есть общий каркас: сеть, модели и репозитории, конфигурация с кэшем по контрольной сумме, тема из палитры, тексты глоссария, пиктограммы SVG, карта osmdroid, навигация, вход, настройки и профиль. Экраны сделки — Э4–Э6 — строятся поверх каркаса без его переделки.

## Принципы

1. **Одна логика — три раскладки.** Каждый экран: `ViewModel` с `StateFlow<UiState>` и действиями. Шаблон выбирает только composable-реализацию: `when (template.screens.home) { "map_sheet" -> HomeA(...); "tiles" -> HomeB(...); "dense_list" -> HomeC(...) }`. Данные, тексты и правила не дублируются.
2. **Интерфейс — данными из БД.** Палитра, шрифт, формы, раскладки, тексты, пиктограммы и курсоры берутся из `GET /config`. В приложении нет зашитых подписей экранов после входа; исключение — экран входа: до входа конфигурации ещё нет, его подписи берутся из ресурсов `values/` и `values-en/`.
3. **Сеть только вне UI-потока.** OkHttp вызывается из `suspend`-функций на `Dispatchers.IO`. В отладочной сборке включён `StrictMode` с `penaltyDeath` на сетевые вызовы в главном потоке: нарушение сразу роняет приложение и не останется незамеченным.
4. **Ошибки API — типом, а не строкой.** `{"error", "code"}` превращается в `ApiError(status, code, message)`, обрыв связи — в `NetworkError`. Экран показывает понятный текст и кнопку «Повторить» (сценарий U-4).
5. **Правила сделки — на сервере.** Приложение показывает действия из поля `actions` сделки и не решает само, что можно делать (нужно для Э4–Э6, каркас это закладывает).

**Почему Kotlin 2.4.21, а не встроенный 2.2.10.** AGP 9.4.0 по умолчанию тянет Kotlin 2.2.10. Текущие `kotlinx-serialization` 1.12 и stdlib собраны Kotlin 2.4, а компилятор 2.2 читает метаданные только до 2.3. Пробная сборка на 2.2.10 падает: «Module was compiled with an incompatible version of Kotlin». Механизм остаётся встроенным в AGP 9 (без плагина `kotlin-android`), меняется только версия в `buildscript`. Альтернатива — остаться на 2.2.10 и откатить библиотеки на версии примерно годичной давности. Не рекомендую: потом всё равно придётся обновляться.

ZXing и Code Scanner подключаются в Э6, когда понадобятся; в списке — чтобы согласовать сразу. На обоих эмуляторах образ `google_apis_playstore`, поэтому Code Scanner и загружаемые шрифты Google работают. Без Google Play шрифт откатывается к системному, приложение работает.

## Проверка связности

- **Порядок.** Сборка (1) — основа всего. Сеть (2) нужна моделям (3) и конфигурации (4). Тема, тексты и пиктограммы (5–7) читают конфигурацию. Карта (8) использует цвета темы и пиктограммы. Оболочка (9) собирает 4–8, экраны 10–12 встают в неё. Каждый шаг опирается только на предыдущие.
- **Вход и конфигурация.** `GET /config` требует сессию. Поэтому порядок такой: вход → конфигурация → тема и тексты. Экран входа единственный живёт на ресурсах приложения. Противоречия с ТЗ нет: ТЗ требует смены подписей после выбора языка, а язык выбирается после входа.
- **Контрольная сумма.** Сервер считает md5 по всей конфигурации агента, включая шаблон, схему и язык. Поэтому после `PUT /config` сумма меняется, а при повторном запуске без изменений совпадает — критерий U-3 проверяем.
- **Языки.** В БД 4 языка (RUS, ENG, KAZ, DEU), тексты `ui.*` — для RUS и ENG (по 90). Для KAZ и DEU сервер подставляет русский текст. В списке языков показываются все 4, как отдаёт `/ui/options`.
- **Карта.** Тайлы tile.openstreetmap.org — только для тестов (политика OSM), отдельный User-Agent обязателен. Офлайн-пакет MBTiles в объём прототипа не входит (ТЗ 2).
- **Безопасность.** Открытый HTTP — только до `127.0.0.1`, `localhost`, `10.0.2.2` (`network_security_config.xml` уже есть). Токен хранится в `SharedPreferences` приложения; пароль не сохраняется.
- **Совместимость.** Экран v0.6 удаляется целиком: он читал `is_selected` и `qr_token`, которых в v0.7 нет. Сделку 6 (кейс A/B/C/D) покажут экраны Э4.

Отклонения и наблюдения:

- При недоступном сервере на старте показывается ошибка с темой по умолчанию, а не кэш конфигурации: экранам всё равно нужны данные сервера.
